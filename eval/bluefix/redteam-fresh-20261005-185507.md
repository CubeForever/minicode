## 红队报告

### 发现
- [可选] 滑动窗口采用增量累加 `window_sum += xs[i] - xs[i-k]`,在长序列且数值量级跨度大时会产生浮点漂移,与"每窗口重新 `sum(window)/k`"的结果不一致 (util.py:12) — 实测 `xs` 为 100000 个 `±1e9` 范围随机浮点、`k=5000` 时,与重算法的最大绝对偏差达 `1.40e-7`(中段 `2.05e-8`、末段 `3.17e-8`)。属滑动窗口法的已知精度-效率折中;规范未提精度要求,故仅作可选提示,不阻断。

### 已证伪的可疑点
- [证伪] `k=0` 触发 `ZeroDivisionError` — `k <= 0` 在 `window_sum/k` 之前拦截,实测 `k=0` 抛 `ValueError`。
- [证伪] 空列表 `[]` 致 `len(xs)=0`,边界 `k > len(xs)` 漏判 — `k<=0` 先拦 `k=0`;`k>0` 时 `k>0` 即 `k>len(xs)` 成立,实测 `moving_average([], 0)` 与 `moving_average([], 1)` 均抛 `ValueError`。
- [证伪] 负数 `k` 未被覆盖 — `k <= 0` 覆盖,实测 `k=-1` 抛 `ValueError`。
- [证伪] `k > len(xs)` 用严格大于导致 `k == len(xs)` 被误拒 — 规范"不超过"即 `≤`,代码用 `k > len(xs)` 恰好允许等于;实测 `moving_average([1,2,3,4],4)==[2.5]`(整体均值),正确。
- [证伪] 结果长度不对 — 起始 1 元素 + 循环 `range(k, n)` 共 `n-k` 次 `append`,总长 `n-k+1`,与 docstring 一致;实测示例 `[1.5,2.5,3.5]` 长度 3 = 4-2+1。
- [证伪] `k=1` 退化为原序列但类型/符号出错 — 实测 `moving_average([1,2,3,4],1)==[1.0,2.0,3.0,4.0]`,正确。
- [证伪] Python 整数除法截断 — `/` 为真除法,结果恒为 float,首元素 `[window_sum/k]` 与后续一致。
- [证伪] 大整数累加溢出 — Python int 任意精度,无溢出;`window_sum` 增减不丢精度(int 情形)。
- [证伪] 失败状态残留半成品 / 异常被吞 — `result` 为纯局部变量,异常抛出后无副作用、无资源持有。
- [证伪] 破坏既有调用点/测试的隐含假设 — 仓库仅 `util.py` 一个文件,无测试、无外部调用点;旧实现恒抛 `NotImplementedError`,新实现是按规范补全,唯一被打破的"假设"就是"未实现"本身,属预期。
- [证伪] 资源/并发/可重入问题 — 纯函数,无文件句柄、无全局、无 I/O,天然可重入。
- [证伪] 注入面(shell/SQL/路径/正则) — 无任何外部输入拼接进解释器/路径/正则。
- [证伪] 平台差异 — 纯算术,无路径分隔符、编码、行尾、信号相关行为。
- [证伪] 非列表可迭代对象(如 generator)抛 `TypeError` 而非 `ValueError` — docstring 明确"返回长度为 `len(xs)-k+1`",契约要求 `xs` 是有长度的序列;`generator` 无 `len()` 属契约外输入。规范只规定"非法 k 抛 ValueError",未要求对非法 `xs` 类型做同样处理。实测 `moving_average((x for x in [1,2,3,4]), 2)` 抛 `TypeError`,属可接受范畴。
