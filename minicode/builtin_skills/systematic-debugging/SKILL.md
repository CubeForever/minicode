# 系统化调试

按顺序执行，禁止跳步：

1. **复现**：用 bash 找到 100% 可复现的命令/输入。不能复现的问题不许改代码。
2. **定位根因**：读相关代码，用最小化输入和二分法缩小范围。明确说出"根因是 X，因为 Y"。
3. **最小修复**：只修根因，不修症状；不做顺手重构。
4. **回归验证**：运行原复现命令 + 相关测试，证明已修复且无回归。把根因一句话写入项目大脑（brain_write, kind=gotcha）。
